
> **Si Python est l'outil principal d'un Data Scientist, SQL est son langage quotidien.**

L'objectif de ce module est de vous rendre capable de résoudre des problèmes SQL complexes et d'expliquer vos choix.

# MODULE 2 – SQL pour Data Scientist (Niveau Expert)

## Objectifs

À la fin de ce module, vous serez capable de :

* Écrire des requêtes SQL complexes.
* Comprendre les plans d'exécution (`EXPLAIN`).
* Utiliser efficacement les `JOIN`, `CTE` et `Window Functions`.
* Optimiser les performances.
* Répondre aux questions d'entretien de niveau intermédiaire à avancé.
